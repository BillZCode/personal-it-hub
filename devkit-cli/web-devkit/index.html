⚡ Go Developer Automation Engine

go build -o bin/devkit main.go

High-performance, idiomatic Go automation engine powered by Cobra & Go Standard Library. Modular, concurrent, and zero unsafe dependencies.

🛠️ PROJECT GENERATOR
devkit init my-api -t go

Scaffolds clean enterprise directories (cmd, internal, pkg, go.mod, git).

🧹 SAFE WORKSPACE CLEANER
devkit clean --dry-run

Audits node_modules, build, dist, and cache folders with confirmation safeguards.

🐳 DOCKER HYGIENE
devkit docker clean

Reclaims gigabytes from dangling images and stopped containers safely.

🔗 MARKDOWN LINK CHECKER
devkit markdown links README.md

Audits internal relative files and external HTTP links concurrently with worker pools.

🩺 DOCTOR DIAGNOSTIC
devkit doctor

Performs system audits across Go, Node, Docker, Git, Python, and SSH.

📦 PROJECT BACKUP
devkit backup . -f tar.gz

Instant compressed snapshot automatically filtering heavy dependencies.
