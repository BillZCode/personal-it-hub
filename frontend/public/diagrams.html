5. Pipeline Moderasi & Anti-Spam Guestbook (Fixed)

sequenceDiagram autonumber actor Visitor as Pengunjung Publik participant FE as Frontend UI (:3000) participant BE as Express API (:3001) participant DB as Prisma / Database actor Admin as Administrator Note over Visitor,DB: 1. Query Publik Hanya Menampilkan yang Disetujui Visitor->>FE: Buka Halaman /guestbook FE->>BE: GET /api/guestbook BE->>DB: SELECT WHERE approved = true ORDER BY createdAt DESC DB-->>BE: Daftar Pesan yang Disetujui BE-->>FE: Tampilkan ke Pengunjung Note over Admin,DB: 3. Moderasi di Panel Admin (/admin/guestbook) Admin->>FE: Buka Halaman Moderasi FE->>BE: GET /api/admin/guestbook (Dengan Cookie JWT) BE->>DB: SELECT Semua Pesan (Pending & Approved) DB-->>BE: Daftar Lengkap BE-->>FE: Render Tab Pending dan Approved Admin->>FE: Klik Setujui atau Hapus FE->>BE: PUT /api/admin/guestbook/:id/approve atau DELETE BE->>DB: UPDATE approved = true atau DELETE Record DB-->>BE: Sukses BE-->>FE: Perbarui UI Real-Time
