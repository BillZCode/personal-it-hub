# AI Chatbot Assistant (Gemini)

Aplikasi Chatbot AI interaktif dan modern berbasis web yang ditenagai oleh **Google Gemini API** (`gemini-3.6-flash` / `gemini-3.1-pro-preview`).

## Fitur Utama
- **Real-time SSE Streaming**: Menampilkan respons kata demi kata secara halus dan instan.
- **Syntax Highlighting & Markdown**: Blok kode rapi dilengkapi tombol salin kode cepat.
- **Riwayat Obrolan (Chat History)**: Mendukung multi-sesi percakapan yang disimpan di peramban lokal (`localStorage`).
- **Desain Glassmorphism Modern**: Tema gelap elegan dan responsif untuk desktop maupun mobile.
- **Konfigurasi Fleksibel**: Pengaturan model, API Key, System Prompt, dan Temperature langsung dari UI.

## Menjalankan Aplikasi

Anda dapat menjalankan server web statis lokal sederhana di dalam folder ini:

```bash
# Menggunakan Python 3:
python3 -m http.server 3000
```

Buka peramban dan akses:
```
http://localhost:3000
```
